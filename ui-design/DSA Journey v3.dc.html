THE BRIEFING · 9 MIN

A binary tree is a node graph where every node points at most two ways. That single constraint is the entire trick: nearly every tree problem collapses into solve the left, solve the right, combine.

This level is pure recursion. Write the base case first — an empty node returns a neutral value — then trust the recursive call. If you catch yourself hand-rolling a stack for a plain traversal, back up and start again.

THE SHAPE OF EVERY SOLUTION
def solve(node): if not node: return NEUTRAL L = solve(node.left) R = solve(node.right) return combine(L, R, node.val)
FIG 1 · THE RECURSIVE SKELETON

Complexity is nearly always O(n) time — every node touched once — and O(h) space for the call stack. Balanced, that h is log n; degenerate, it's n. Interviewers ask about exactly that gap.

One real trap this level: diameter. What you return upward (height) is not what you record (the path through the node). Keep the two separate or stage 3 will quietly beat you.
