WEEK 07

Binary Trees

2 / 5 DONE
THE EXPLAINER · 9 MIN READ

A binary tree is a node graph where every node points at most two ways. That constraint is the whole trick: almost every tree problem reduces to "solve the left side, solve the right side, combine."

This week we work exclusively in recursion. Write the base case first — an empty node returns a neutral value — then trust the recursive call. The moment you find yourself tracking a manual stack for a plain traversal, back up.

THE PATTERN
def solve(node): if not node: return NEUTRAL L = solve(node.left) R = solve(node.right) return combine(L, R, node.val)

Complexity is nearly always O(n) time — you touch every node once — and O(h) space for the call stack, where h is height. On a balanced tree that's O(log n); on a degenerate one it's O(n). Interviewers ask about that gap constantly.

The one genuine trap this week is diameter: the answer you return upward (height) is not the answer you record (path through the node). Keep them separate.
