THE BRIEFING

A binary tree is a node graph where every node points at most two ways. That single constraint is the whole trick: almost every tree problem collapses into solve the left, solve the right, combine.

This level is pure recursion. Write the base case first — an empty node returns a neutral value — then trust the recursive call. If you catch yourself hand-rolling a stack for a plain traversal, back up.

THE PATTERN
def solve(node): if not node: return NEUTRAL L = solve(node.left) R = solve(node.right) return combine(L, R, node.val)

Complexity is nearly always O(n) time — every node touched once — and O(h) space for the call stack. Balanced, that's O(log n); degenerate, it's O(n). Interviewers ask about exactly that gap.

The one real trap: diameter. What you return upward (height) is not what you record (path through the node). Keep them separate and stage 3 falls over.
